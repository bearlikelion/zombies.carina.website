# zombies.carina.website

The leaderboard for the Holdfast zombie Halloween event, hosted by CarinaMachina.

Visit it at [zombies.carina.website](https://zombies.carina.website).

## What's on the site

- **Top Honors:** the standout players of the event.
- **Leaderboard:** every player's kills, deaths, time alive and points.
- **Player profiles:** each player's totals, honors, maps, weapons and recent rounds.
- **Campaign report:** how each event went, from lives lost to the deadliest map.

## How points work

- 10 points for each human you kill as a zombie.
- 5 points for each zombie you kill as a human.
- 1 point for each minute you stay alive as a human.
- 25 points for each round you survive to the end.

## How it updates

The server records every round as it's played.
The site picks up new results every few minutes while people are playing.
